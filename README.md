# TapeBuster

**Play it here: https://marcopolo2350.github.io/tapebuster-pages/**

A walkable, late-90s video rental superstore in your browser: 122,948 catalogued
titles, a 20,000-case sales floor across two levels, six escalators, browsing
NPCs, and an in-store radio station whose every note is generated — no audio
files, no samples.

Walk with **WASD** (Shift to hurry), drag to look, click a case to pick it up,
click an escalator to ride it. Ask the clerk for a recommendation, build a
stack, and check out at the counter.
